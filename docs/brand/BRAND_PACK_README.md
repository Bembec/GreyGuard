# GreyGuard Brand Assets

This package contains GreyGuard's approved working brand references and practical raster assets for the web application.

## Approved identity

- Name: **GreyGuard**
- Tagline: **SECURE • MONITOR • CONTROL**
- Symbol: metallic shield containing the letter G
- Visual character: professional, high-trust enterprise security

## Application usage

- Use `logos/primary/greyguard-primary-stacked.png` for splash, login and onboarding screens.
- Use `logos/horizontal/greyguard-horizontal-dark.png` in wide headers and expanded navigation.
- Use `logos/symbol/greyguard-symbol-dark.png` for collapsed navigation and loading states.
- Use the files under `icons/` for browser, PWA and application metadata.
- Retain adequate clear space around the mark and never stretch, rotate or recolour it.

## Important production note

The approved source artwork supplied here is raster artwork. The PNG, WebP and icon files in this package are production-usable raster derivatives. A designer should redraw and approve a true vector master before any file is described as an official SVG/vector master. Do not auto-trace the detailed metallic artwork and present it as an authoritative vector.

See `brand-guide/GreyGuard_Brand_Guide.md` and `production-checklist/REMAINING_VECTOR_AND_PRINT_WORK.md`.
