# Security policy

Do not open public issues containing credentials, personal data, exploit details, or production evidence. Report suspected vulnerabilities privately through GitHub Security Advisories for this repository. Include affected version, impact, reproduction steps, and a safe proof of concept. Do not access data you do not own, degrade services, or perform social engineering. Maintainers should acknowledge a report within five business days, triage severity, prepare a tested fix, and coordinate disclosure after affected deployments have had reasonable time to update.
