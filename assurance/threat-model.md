# GreyGuard threat-model review

Review assets, trust boundaries, threat actors, attack paths, existing controls, residual risk, test evidence, response owner, and review date for each release.

Priority threats include credential theft and replay, scope escalation, cross-agent access, approval bypass, confused-deputy behavior, prompt injection influencing tool use, malicious tool output, path or symlink escape, sandbox escape, SSRF, command/SQL injection, XSS/CSRF, insecure direct object reference, evidence tampering, races and double execution, denial of service, dependency compromise, malicious integrations, excessive retention, administrator misconfiguration, insider misuse, unsafe automatic response, kill-switch failure, and recovery failure.

No review may convert prohibited behavior into an operational capability. Record detection, blocking, containment, evidence preservation, recovery, and accepted residual risk.
